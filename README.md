# Resolved

An original offline office game in simple 3D: you work at a desk in an open office and stamp endless requests with stretchy arms; shout-outs, awards and swag buy the Skill Tree, the team and gear.

**Play:** https://g-zack-nguyen.github.io/resolved/

It plays in any current browser - Safari, Chrome, Firefox or Edge - on a phone or a computer.

## On an iPhone

1. Open the link above in Safari.
2. Tap the Share button, then **Add to Home Screen**.
3. Start Resolved from the Home Screen once while you are online. After that it plays offline too.

**Add it to the Home Screen before you play, and play from there.** The Home Screen app has its own save:
progress made in a Safari tab stays in Safari. To bring it over, open Settings > Save in the Safari tab and tap
**Copy save code**. Then open the Home Screen app, go to Settings > Save, paste the code into the Import box and
tap **Import**.

It is made for portrait, one thumb. Progress is saved on the device only; Settings > Save > Copy save code and
Import move it to another device. There is no account and no server: the game never sends anything anywhere.
Each workplace is its own career with its own code: copy it in each one (Settings > Workplace switches).
